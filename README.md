# Birthday Funk — Remotion

Вертикальный музыкальный клип **1080 × 1920, 30 fps, 48,03 секунды**. Только 11 оригинальных видеозаписей из предоставленной папки Google Drive и `happy-birthday-funk-spot-16197.mp3`. Генеративные модели, синтетические видео, изображения и озвучка не используются.

## Установка и запуск

Нужны Node.js 22+ (проверено с 24.19), npm, Python 3, FFmpeg/FFprobe и Chromium. На Linux браузер автоматически берётся из `/usr/bin/chromium`; другой путь задаётся переменной `REMOTION_BROWSER_EXECUTABLE`. Если системного браузера нет, Remotion использует собственную загрузку Chrome.

```sh
cd editor
npm ci
npm run download:media
npm run check:media
npm run studio
```

Оригиналы скачиваются по публичным идентификаторам Google Drive и сверяются с SHA-256. Они остаются в `editor/public/media/`, в Git не добавляются. Если доступ к Drive закрыт, скачивание завершается ошибкой — подмена материала не предусмотрена.

```sh
npm run typecheck
npm test
npm run build
npm run render
```

Готовый файл: `editor/out/birthday-funk.mp4`, H.264, AAC, yuv420p, CRF 18. Рендер использует 2 параллельных потока; на более мощной машине можно запускать CLI с большим `--concurrency`.

## Монтаж

35 сцен: сольные планы, дуэты рядом и трио с широким верхним планом и двумя нижними. В монтаже задействованы все 11 видео. Частота смены планов нарастает от четырёх долей до одной, завершение — общий оркестр. Музыка сохраняет исходную скорость; звук камер отключён.

Ритм музыки оценивается детерминированным анализом энергии и автокорреляции (около 140 BPM). Пики движения исходников помогают выбрать акценты и скорость 0,8–1,3×. Это ритмический монтаж, а не точная реконструкция исполнения музыкантов: ручное уточнение акцентов возможно в Studio. Покадровая коррекция экспозиции, контраста, насыщенности  применяется к оригиналам. Размытое заполнение вокруг общего оркестра берётся из той же записи.

- `editor/src/BirthdayFunk.tsx` — отдельный JSX-узел для каждой сцены и каждого участника; тайминг и скорость можно редактировать независимо.
- `editor/src/components/Shot.tsx` — компоновка дуэтов/трио и цветокоррекция.
- `editor/src/manifest.json` — монтажная карта и диапазоны оригиналов.
- `editor/src/analysis.json` — результаты анализа музыки и движения.
- `editor/scripts/timeline.mjs` — воспроизводимый монтажный план.
- `editor/scripts/drive-files.json` — происхождение и контрольные суммы материалов.

`npm run prepare:media` повторяет анализ и **перезаписывает** `src/BirthdayFunk.tsx`, `manifest.json` и `analysis.json`; сначала сохраните ручные правки в Git. Для обычного запуска и рендера повторная генерация не нужна.

Проверки подтверждают целостность оригиналов, использование всех видео, отсутствие пустых интервалов и выходов за длительность исходников. После ручного изменения JSX обновите также монтажную карту и проверки согласованности.
